# ArchiMate 3.2 元素目录

## 战略层元素 (Strategy Layer)

### Resource (资源)
- **定义**: 组织拥有或控制的资产
- **符号**: 矩形，右上角有对角线
- **颜色**: #F5DEAA (浅黄)
- **用途**: 描述战略资源如资金、人力、技术等

### Capability (能力)
- **定义**: 组织拥有的能力，用于实现战略目标
- **符号**: 圆角矩形
- **颜色**: #F5DEAA
- **用途**: 能力建模、能力差距分析

### Value Stream (价值流)
- **定义**: 端到端创造价值的活动序列
- **符号**: 箭头形状
- **颜色**: #F5DEAA
- **用途**: 价值流分析、端到端流程优化

### Course of Action (行动方案)
- **定义**: 实现目标的具体行动方案
- **符号**: 圆角矩形带箭头
- **颜色**: #F5DEAA
- **用途**: 战略规划、行动计划

## 业务层元素 (Business Layer)

### 主动结构元素

#### Business Actor (业务参与者)
- **定义**: 能够执行行为的组织单元或个人
- **符号**: 人形图标
- **颜色**: #FFFFB5 (黄色)
- **示例**: 客户、供应商、员工

#### Business Role (业务角色)
- **定义**: 参与者在特定行为中承担的责任
- **符号**: 黄色人形带圆角
- **颜色**: #FFFFB5
- **示例**: 审批者、申请人、管理员

#### Business Collaboration (业务协作)
- **定义**: 多个角色的临时配置
- **符号**: 两个人形重叠
- **颜色**: #FFFFB5
- **示例**: 项目团队、工作组

#### Business Interface (业务接口)
- **定义**: 业务服务的访问点
- **符号**: 矩形带垂直线
- **颜色**: #FFFFB5
- **示例**: 客户服务台、网站入口

### 行为元素

#### Business Process (业务流程)
- **定义**: 基于事件顺序产生特定结果的行为
- **符号**: 圆角矩形带箭头
- **颜色**: #FFFFB5
- **示例**: 订单处理流程、客户注册流程

#### Business Function (业务功能)
- **定义**: 基于选定标准分组的行为
- **符号**: 圆角矩形
- **颜色**: #FFFFB5
- **示例**: 财务管理、人力资源管理

#### Business Service (业务服务)
- **定义**: 明确定义的行为，提供给消费者
- **符号**: 圆角矩形上边弧形
- **颜色**: #FFFFB5
- **示例**: 账户开户服务、贷款申请服务

#### Business Event (业务事件)
- **定义**: 触发或影响行为的组织状态变化
- **符号**: 圆角矩形带闪电
- **颜色**: #FFFFB5
- **示例**: 订单提交、付款完成

#### Business Interaction (业务交互)
- **定义**: 协作中执行的行为
- **符号**: 圆角矩形双边线
- **颜色**: #FFFFB5

### 被动结构元素

#### Business Object (业务对象)
- **定义**: 业务领域的概念
- **符号**: 矩形
- **颜色**: #FFFFB5
- **示例**: 订单、客户、产品

#### Contract (合同)
- **定义**: 参与者间的正式或非正式协议
- **符号**: 矩形带折角
- **颜色**: #FFFFB5
- **示例**: 服务协议、采购合同

#### Representation (表示)
- **定义**: 业务对象的感知形式
- **符号**: 文档图标
- **颜色**: #FFFFB5
- **示例**: 报告、表单、文档

#### Product (产品)
- **定义**: 提供给客户的一系列服务的组合
- **符号**: 矩形带方框
- **颜色**: #FFFFB5
- **示例**: 银行产品、保险产品

## 应用层元素 (Application Layer)

### Application Component (应用组件)
- **定义**: 封装应用功能的模块化、可部署、可替换的单元
- **符号**: 矩形带小方块
- **颜色**: #B5FFFF (青色)
- **示例**: CRM系统、ERP模块

### Application Collaboration (应用协作)
- **定义**: 多个应用组件的临时配置
- **符号**: 两个组件重叠
- **颜色**: #B5FFFF

### Application Interface (应用接口)
- **定义**: 应用服务的访问点
- **符号**: 圆形/椭圆
- **颜色**: #B5FFFF
- **示例**: API、Web Service

### Application Function (应用功能)
- **定义**: 应用组件执行的自动化行为
- **符号**: 圆角矩形
- **颜色**: #B5FFFF

### Application Service (应用服务)
- **定义**: 应用组件暴露的自动化行为
- **符号**: 圆角矩形上边弧形
- **颜色**: #B5FFFF
- **示例**: 用户认证服务、数据查询服务

### Application Process (应用流程)
- **定义**: 应用组件执行的流程
- **符号**: 圆角矩形带箭头
- **颜色**: #B5FFFF

### Application Event (应用事件)
- **定义**: 应用状态变化
- **符号**: 圆角矩形带闪电
- **颜色**: #B5FFFF

### Data Object (数据对象)
- **定义**: 用于自动处理的数据
- **符号**: 矩形带折角
- **颜色**: #B5FFFF
- **示例**: 客户记录、交易记录

## 技术层元素 (Technology Layer)

### Node (节点)
- **定义**: 计算资源
- **符号**: 3D 方块
- **颜色**: #C9E7B7 (绿色)
- **示例**: 服务器、虚拟机、容器

### Device (设备)
- **定义**: 物理计算资源
- **符号**: 3D 方块带底座
- **颜色**: #C9E7B7
- **示例**: 物理服务器、路由器、交换机

### System Software (系统软件)
- **定义**: 在节点上运行的软件平台
- **符号**: 3D 方块带条纹
- **颜色**: #C9E7B7
- **示例**: 操作系统、数据库、中间件

### Technology Interface (技术接口)
- **定义**: 技术服务的访问点
- **符号**: 半圆形
- **颜色**: #C9E7B7

### Path (路径)
- **定义**: 节点间的物理通信链接
- **符号**: 线条
- **颜色**: #C9E7B7

### Communication Network (通信网络)
- **定义**: 物理或逻辑通信基础设施
- **符号**: 管道形
- **颜色**: #C9E7B7
- **示例**: LAN、WAN、互联网

### Technology Service (技术服务)
- **定义**: 技术层暴露的服务
- **符号**: 圆角矩形上边弧形
- **颜色**: #C9E7B7

### Technology Function (技术功能)
- **定义**: 技术行为
- **符号**: 圆角矩形
- **颜色**: #C9E7B7

### Technology Process (技术流程)
- **定义**: 技术流程
- **符号**: 圆角矩形带箭头
- **颜色**: #C9E7B7

### Technology Event (技术事件)
- **定义**: 技术状态变化
- **符号**: 圆角矩形带闪电
- **颜色**: #C9E7B7

### Artifact (制品)
- **定义**: 物理数据或软件制品
- **符号**: 文件图标
- **颜色**: #C9E7B7
- **示例**: WAR包、配置文件、脚本

## 动机层元素 (Motivation Layer)

### Stakeholder (利益相关者)
- **定义**: 对架构有利益关系的个人或组织
- **符号**: 人形
- **颜色**: #CCCCFF (紫色)

### Driver (驱动因素)
- **定义**: 创建或约束架构的外部条件
- **符号**: 椭圆带箭头
- **颜色**: #CCCCFF

### Assessment (评估)
- **定义**: 对驱动因素影响的评估
- **符号**: 椭圆
- **颜色**: #CCCCFF

### Goal (目标)
- **定义**: 想要达到的高层级状态
- **符号**: 椭圆带垂直线
- **颜色**: #CCCCFF

### Outcome (结果)
- **定义**: 期望达到的端到端结果
- **符号**: 椭圆带波浪
- **颜色**: #CCCCFF

### Principle (原则)
- **定义**: 指导决策的规范性声明
- **符号**: 矩形三角顶
- **颜色**: #CCCCFF

### Requirement (需求)
- **定义**: 必须实现的能力
- **符号**: 矩形弧形底
- **颜色**: #CCCCFF

### Constraint (约束)
- **定义**: 对实现的限制
- **符号**: 矩形八角
- **颜色**: #CCCCFF

### Meaning (含义)
- **定义**: 概念的知识或专业理解
- **符号**: 云形
- **颜色**: #CCCCFF

### Value (价值)
- **定义**: 元素的相对价值
- **符号**: 椭圆星形
- **颜色**: #CCCCFF

## 实施与迁移层元素 (Implementation & Migration)

### Work Package (工作包)
- **定义**: 可交付的工作单元
- **符号**: 矩形带折角
- **颜色**: #FFE0E0 (粉色)

### Deliverable (交付物)
- **定义**: 工作包的输出
- **符号**: 文档图标
- **颜色**: #FFE0E0

### Implementation Event (实施事件)
- **定义**: 实施状态变化
- **符号**: 矩形带闪电
- **颜色**: #FFE0E0

### Plateau (高原/阶段)
- **定义**: 架构的相对稳定状态
- **符号**: 矩形堆叠
- **颜色**: #FFE0E0

### Gap (差距)
- **定义**: 两个平台间的差异
- **符号**: 矩形虚线
- **颜色**: #FFE0E0
